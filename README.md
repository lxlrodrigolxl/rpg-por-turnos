# Sistema de RPG por Turnos — Paradigmas de Programação

Projeto desenvolvido para a disciplina de **Paradigmas de Programação**, com o objetivo de demonstrar na prática a aplicação do paradigma de **Programação Orientada a Objetos (POO)** e seus pilares fundamentais.

---

## 🎯 Objetivo do Projeto

Simular um jogo de RPG de combate por turnos executado via terminal, demonstrando o fluxo de ações entre o jogador e o oponente com base na estruturação em objetos.

---

## 🏛️ Aplicação dos 4 Pilares da POO

O projeto foi estruturado aplicando os conceitos clássicos da orientação a objetos:

1. **Abstração:** Mapeamento das regras do jogo em classes e modelos computacionais.
2. **Encapsulamento:** Restrição e controle de acesso aos atributos dos personagens (ex: pontos de vida e status de combate).
3. **Herança:** Estruturação de classes base para reaproveitamento de código entre diferentes tipos de entidades.
4. **Polimorfismo:** Implementação de comportamentos específicos para os métodos de ação e ataque de cada classe.
